# Development Journal, November 15th, 2023

This is my first entry in the development journal for VAL.
These journals are being written mostly for my own memory, so don't expect to get much, if anything, from them, if you aren't me.

The idea with VAL - short for Vernacular Activity Ledger - is to implement a "ledger" software where each "entry" has an associated "act" that determines how the rest of the entry's information is integrated into the "map" that the system makes of the information across entries.

I'm using Replit's AI heavily to guide development, which is being done with Node.js for the VAL system itself, and Express.js for the primary browser interface.

This first day, my intention is to prototype the functions that'll let me add events to ledgers, and start building maps from those entries - but the second part will be very rudimentary: my focus is on getting it quickly to the point where a person can use the browser interface to add new entries to ledgers, even if there isn't anything to interpret the acts yet.
