# @red-cup-engineering/jsnode-topology

Node.js packages as a meme-topology carrier: layer, exports, and dependencies as relational utterances; workspace-level sheaf settlement via induceJSNodeTopology.

## Dependencies

- `@red-cup-engineering/javascript-algebra`
- `@red-cup-engineering/agentic-relation-engine` supplies the maintained utterance and settlement kernels.

The latter replaces the archived `@emsenn/meme-topology` dependency without
restoring its unpublished `meme-algebra` and `meme-logic` closure. The public
JSNode carrier still exposes its witnessed utterances, fixed-point readings,
and settlement, now computed by the current Relating owner.

## Capability discovery

`searchPackages(packages, query, context?)` is the pure capability-discovery
read used by JSNode transports. It ranks package names, keywords, and
descriptions; expands an explicitly supplied term/alias vocabulary; and reports
every source-declared consumer with its dependency kind and range.

Delivery evidence is kept separate from source metadata. Callers may supply
observed published releases, installations, and live endpoints. The result only
calls a package `source-only` when the caller marks that external-path assay
complete; otherwise it says `source-with-unassayed-delivery`. A package version,
public flag, dependency declaration, or server configuration is never silently
promoted into evidence that a release is published, installed, or live.
