## Verified acceptance cases

Specification basis. Node.js Runtime text-tier invocation. Callers address operations by qualified domain and name. The shared Code interpreter handles a registered operation's typed request.

| Case | Check | Behavior |
| --- | --- | --- |
| ` NODE-RUNTIME-NAMESPACE ` | source refusal | A bare operation name is refused at the text-tier boundary. |
| ` NODE-RUNTIME-DISPATCH ` | source invariant | The text tier can dispatch operations in two domains by their qualified names. |
| ` NODE-RUNTIME-QUICKSTART ` | consumer example | An installed consumer invokes a named text operation and receives its typed result. |

Runtime requirement. ` >=24.2.0 `
