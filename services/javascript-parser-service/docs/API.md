## Verified acceptance cases

Specification basis. Read JavaScript source as a module syntax tree with exact spans without executing the program.

| Case | Check | Behavior |
| --- | --- | --- |
| ` JS-PARSER-REFUSAL ` | source refusal | A declaration without a binding name refuses with SyntaxError. |
| ` JS-PARSER-QUICKSTART ` | consumer example | An installed reader can identify an exported constant and inspect its literal initializer. |

Runtime requirement. ` >=18 `
