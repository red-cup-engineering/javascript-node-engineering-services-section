# VAL (Vernacular Activity Ledger)

Vernacular Activity Ledger (VAL) is a system for recording and maintaining various activities and their associated data.
It provides functionality to create and manage ledgers, add and query entries, and view data maps.

## Usage

Too alpha to be used!

## Installation

To install VAL, clone the repository and run it using Node.js.

## Getting Started

1. Clone the repository
2. Install dependencies using `npm install`
3. Start the VAL app using `node index.js`
4. Interact with VAL by accessing its RESTful API endpoints
